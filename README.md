# Калькулятор вывода · CashFlow

Устанавливаемое веб-приложение (PWA). Основной файл — `index.html`; расчётная логика взята из последней версии исходного калькулятора.

## Публикация на GitHub Pages
1. Распакуйте архив.
2. Загрузите **всё содержимое папки `CashFlow-PWA`** в корень репозитория GitHub, сохранив папку `assets`.
3. В GitHub откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
5. Сохраните и дождитесь публикации сайта по HTTPS.

## Установка на Android
1. Откройте опубликованный адрес в Google Chrome.
2. Нажмите меню Chrome (⋮).
3. Выберите «Установить приложение» и подтвердите установку.

## Добавление на экран iPhone
1. Откройте опубликованный адрес в Safari.
2. Нажмите «Поделиться».
3. Выберите «На экран „Домой“» → «Добавить».

## Состав
- `index.html` — приложение и встроенные стили/скрипты.
- `manifest.webmanifest` — имя, режим отображения и иконки PWA.
- `sw.js` — Service Worker и кэширование оболочки.
- `assets/icon.svg` — SVG-иконка и favicon.
- `assets/icon-192.png` — иконка для Android и iOS.
- `assets/icon-512.png` — иконка высокого разрешения.
- `assets/icon-maskable-512.png` — адаптивная maskable-иконка Android.

Для установки PWA на Android требуется HTTPS. После обновления файлов обновлённый Service Worker использует новый ключ кэша.
