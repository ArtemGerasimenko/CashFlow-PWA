# CashFlow — обновление иконки калькулятора

Это полный комплект файлов для замены в корне GitHub-репозитория калькулятора.

## Установка обновления
1. Распакуйте ZIP-архив.
2. Загрузите **содержимое этой папки** в корень существующего GitHub-репозитория, сохранив папку `assets`.
3. Подтвердите замену `index.html`, `manifest.webmanifest` и `sw.js`.
4. Убедитесь, что в корне опубликованы `index.html`, `manifest.webmanifest`, `sw.js`, а внутри `assets` находятся четыре файла иконок.
5. Дождитесь обновления GitHub Pages.

## После публикации
Chrome может продолжать показывать значок уже установленного PWA из данных приложения. Удалите старый ярлык/установленное приложение и установите его заново после обновления сайта. Если меню установки всё ещё показывает старую иконку, откройте сайт в Chrome, обновите страницу и повторите установку.

## Состав
- `index.html` — калькулятор; расчётная логика сохранена.
- `manifest.webmanifest` — PWA-манифест с новыми PNG-иконками.
- `sw.js` — Service Worker с новым именем кэша.
- `assets/icon.svg` — SVG-иконка.
- `assets/icon-192.png` — иконка 192×192.
- `assets/icon-512.png` — иконка 512×512.
- `assets/icon-maskable-512.png` — maskable-иконка 512×512.
