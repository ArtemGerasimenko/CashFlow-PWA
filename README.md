# CashFlow — Android PWA

Это устанавливаемое веб-приложение на основе исходного `withdrawal-calculator.html`.
Расчётная логика исходного калькулятора не переписывалась.

## Установка на Android
1. Разместите содержимое этой папки на HTTPS-хостинге (например, GitHub Pages).
2. Откройте опубликованный адрес в Chrome на Android.
3. Нажмите меню Chrome (⋮) → «Установить приложение» или «Добавить на главный экран».
4. Запустите CashFlow с новой иконки.

## Важно
- Установка PWA требует HTTPS (или localhost для тестирования).
- После первой успешной загрузки оболочка приложения доступна офлайн.
- Данные и настройки, которые калькулятор хранит в localStorage, остаются в браузерном хранилище этого приложения.
- Для публикации на GitHub Pages загрузите все файлы и папку `assets`, сохранив структуру.
